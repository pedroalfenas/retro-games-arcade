# RetrôGames Arcade

## Descrição:
O projeto se baseia nos estabelecimentos de jogos antigos e fliperama, comuns décadas atrás.
Foi proposto por um meu professor para testar meus conhecimentos de html e css.

## Requisitos:
* Ter pelo menos 5 páginas HTML
* Ter apenas 1 página CSS
* Deixar o código limpo e de fácil entendimento

## Objetivo:
Meu objetivo fazendo esse projeto foi de consolidar minha base nessas 2 linguagens e fazer um código limpo.
Também quero aumentar meu portifólio no GitHub, para ter mais projetos à mostra.

## Nota Importante:
O código de JavaScript e os IDs relacionados foram fornecidos pelo meu professor com o objetivo de introduzir o JS para ter uma impressão, portanto, essa parte do código não pertence a mim

## Como adicionar no seu computador?
